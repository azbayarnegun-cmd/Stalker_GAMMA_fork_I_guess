ToxicAir BigCanisters v3
========================

Big 1x3 oxygen tanks with the prices and balance of
"Toxic Air economy rebalance for GAMMA".

WHERE THE VALUES COME FROM
  - Everything (stats, balance, prices): Toxic Air economy rebalance for GAMMA
  - Tank size and icons (icons_texture, inv_grid_*): BigCanisters v2
    -> the 5 oxygen tanks use ui\ui_oxygen_tank_big.dds, 1 wide x 3 tall

REQUIRES
  - Toxic Air v2 REDUX (by Priler)

INSTALL / MO2 ORDER
  Toxic Air v2 REDUX
  ToxicAir BigCanisters v3   <- after Redux

  Disable "Toxic Air economy rebalance for GAMMA" and "ToxicAir BigCanisters v2".
  All three ship configs\items\items\items_oxygentanks.ltx, so only one is used.
  v3 already contains everything from both.
