# Composure Weapon Handling v1 — Live test plan

Use a disposable save. Record the original values/feel of several weapon classes before enabling the addon.

## Required values

Use **MCM → Composure - Weapon Handling → Enable handling preview**. The preview is local to this addon and must not change the Framework value shown by Feedback HUD.

Test at:

```text
100, 86, 85, 70, 69, 60, 50, 49, 40, 39, 16, 15, 1, 0
```

Confirm there is no effect at 70–100 or 0, a subtle start at 69, and smooth strengthening toward Breaking Point.

Disable preview after the test. Press F11 (or the configured diagnostic key) and confirm the log reports the real Framework value again.

## Counterplay

At 60, 45, 25, and 10, compare:

1. Standing still, waiting, then firing one shot.
2. Crouching, waiting, then firing one shot.
3. Walking into ADS and firing immediately.
4. Sprinting, stopping, entering ADS, and firing immediately.
5. Firing single shots, short bursts, and full automatic fire.

Crouching and waiting should help. They must not erase the Composure ceiling. A prepared first shot should remain more useful than an uncontrolled burst.

## Native values and cleanup

For pistols, rifles, shotguns, DMRs, and sniper rifles:

1. Equip the weapon and note recoil/ADS behavior.
2. Trigger low Composure effects.
3. Disable Weapon Handling in MCM while the weapon is active.
4. Confirm the original behavior returns.
5. Re-enable, switch weapons repeatedly, and confirm no cumulative drift.
6. Change level while effects are active and confirm restoration.
7. Save/load with effects active and confirm a fresh baseline is captured.
8. Add/remove an attachment, switch away and back, and confirm the new baseline is respected.

## GAMMA Enhanced Recoil

Test with Enhanced Recoil enabled and disabled. Verify camera motion remains playable at maximum Composure Weapon settings, particularly on automatic weapons and high-recoil shotguns. Reduce Weapon Handling recoil strength if the combination is excessive.

## Event API

Apply a temporary 0.25 disturbance for 0.8 seconds. Confirm stability falls, recovers after expiry, and the disturbance does not persist through a level change. Test two simultaneous owner-scoped disturbances and owner cleanup.

## Safety

Confirm:

- Damage, penetration, muzzle velocity, ammunition, condition, and shot dispersion are unchanged.
- No involuntary firing, weapon drops, or input locks occur.
- No camera motion is generated by the base sway module.
- Disabling the addon restores every captured native field.
- Missing optional setters log an isolated failure without breaking Framework or other modules.
- No breathing, heartbeat, status-thought, HUD, visual, stamina-drain, or Composure-writing code is present.
